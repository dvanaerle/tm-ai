# Shared brand references

The Tuinmaximaal design system lives in the [`tuinmaximaal-design`](../../skills/tuinmaximaal-design/SKILL.md) skill. Its [DESIGN.md](../../skills/tuinmaximaal-design/DESIGN.md) is the only active design document: its tokens are generated from the Valantic `base` theme, and it holds the brand prose (audience, principles, visual rules). Edit the prose there and regenerate the tokens with `npm run design:sync`.

Tone of voice is owned by the `tuinmaximaal-copy` skill. The former design document is archived in [`archive/legacy-design/`](../../archive/legacy-design/README.md).
